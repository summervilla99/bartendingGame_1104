**어두운 마호가니 톤의 리스닝 라운지에서, 칵테일을 만들고 사람들의 이야기를 듣는 3D 바텐딩 게임**

## 소개

Bar Coda는 "곡의 마지막 맺음(코다)"에서 이름을 따온 리스닝 라운지 바를 배경으로 합니다. 진한 적갈색 마호가니, 옥스블러드 가죽, 산화된 황동, 낮은 호박색 조명, 한쪽에는 그랜드 피아노. 지나치게 화려하기보다 **조용하고 고급스러운 분위기**를 가장 중요하게 만들었습니다.

바 안을 걸어 다니다가 카운터 안쪽으로 들어가면 바텐더 시점으로 바뀌고, 손님이 주문한 칵테일을 직접 따르고, 흔들고, 젓고, 장식해서 내어 줍니다. 잘 만들면 별점과 팁을, 손님의 이야기에 귀 기울이면 7일 밤에 걸친 이야기를 얻습니다.

## 플레이 방식

게임을 열면 세 가지 중 하나를 고릅니다.

| 모드 | 설명 |
| --- | --- |
| **스토리** | 단골들과 대화하고, 그날 기분에 맞는 술을 골라 내고, 7일 밤의 이야기를 따라갑니다. 혼자 하기 전용. |
| **친구와 함께** | 방을 만들어 링크나 5자리 코드로 친구를 초대합니다. 걸어 다니는 손님과 카운터 안의 바텐더를 오가며 같이 즐깁니다. 최대 8명. |
| **칵테일 연습** | 혼자 손님을 받으며 레시피를 익힙니다. 시간대, 메뉴 계열, 제한시간을 고를 수 있습니다. |

### 한 잔을 만드는 과정

`붓기 → 흔들기/젓기 → 따라내기 → 가니시 → 서빙 → 별점 · 팁`

- **붓기**: 재료 칩이나 선반의 병을 꾹 누르면 병이 기울어 따라집니다. ml · oz가 함께 표시됩니다.
- **방식 3가지**: 과즙·시럽이 들어가면 **셰이크**(셰이커를 흔들어 얼음을 부딪힘), 술로만 만들면 **스터**(믹싱 글라스와 바 스푼으로 원을 그리며 젓기), 섞지 않으면 **빌드**(잔에 바로).
- **점수**: 정확도 70% + 섞은 정도 20% + 가니시 10%. 별 1~3개와 팁이 정해집니다.
- 칵테일 24종(하우스 오리지널 3종 포함), 재료 26종, 잔 11종. 레시피마다 어울리는 잔과 얼음 규칙이 따로 있고, 주문서에 서빙 팁과 이유가 함께 적혀 있어 **바텐딩을 몰라도 배우면서 할 수 있습니다.**

## 주요 기능

- 🎬 **스토리 7일 밤**: 이야기, 선택지, 분위기 주문(추천 술 고르기), 관계도(하트), 서윤 × 윤하의 인연에 따라 갈리는 **3가지 엔딩**. 6~7일 밤에는 3D 스틸 컷이 들어갑니다.
- 👫 **온라인 방**: 같은 방의 친구가 칵테일을 만드는 모습이 실시간으로 보입니다(병이 기울고, 잔이 차오르고, 셰이커가 흔들립니다). 앉기, 채팅(기록 열람 포함), 이모트(건배/손 흔들기/박수/인사/춤/점프), 포토 모드를 지원합니다.
- ⏱ **제한시간**: 없음/60/45/30초를 시작 메뉴와 게임 안 설정에서 켜고 끌 수 있습니다. 혼자 할 땐 손님이 떠나고, 친구 방에선 바텐더가 해고됩니다.
- 🎁 **콤보·단골·급한 손님**: 연속 2성 이상은 팁 보너스, 같은 손님에게 3성을 두 번 주면 단골, 급한 손님은 팁 1.5배.
- 📒 **바 노트**: 3성을 받으면 손님이 방명록에 폴라로이드를 붙이고, 만든 칵테일마다 코스터가 모입니다.
- 🐈 **카운터 고양이**: 서빙 결과에 따라 점프하거나 고개를 돌립니다.
- 🎄 **크리스마스 장식**: 트리, 가랜드, 리스, 눈, 산타 모자(설정에서 끌 수 있고 스토리에서는 나오지 않습니다).
- 🎵 **라이브 음악**: 재즈/클래식/하우스를 즉석에서 합성해 들려줍니다. 피아노 의자에 앉으면 장르를 바꿀 수 있습니다.
- 🌗 **시간대**: 골든아워, 프라임타임, 라스트콜. 조명과 창밖 풍경, 손님 수, 팁 배율이 달라집니다.
- 📱 **모바일 우선**: 세로 화면, 터치 조이스틱, 두 손가락 확대, 44px 이상의 터치 영역.
- 🌐 **한국어 / English**: 상단 KO/EN 토글, 기기 언어를 기본으로 따릅니다.

## 기술

- **three.js r128 + Vite**, 바닐라 JS. 프레임워크 없이 만들었습니다.
- **에셋 파일이 없습니다.** 모델은 코드로 만든 지오메트리, 텍스처는 캔버스, 소리와 음악은 WebAudio로 즉석 합성합니다. 빌드 결과물은 약 1MB입니다.
- 후처리: 4x MSAA 하프플로트 → 블룸 → 톤 숄더, 비네트, 색수차, 그레인. 환경 맵은 작은 가짜 스튜디오 씬을 PMREM으로 구워서 유리, 황동, 액체의 반사를 냅니다.
- **게임 규칙은 `src/game/` 에만** 있고(three/DOM 없음, JSON 직렬화), 화면은 그 결과를 그리기만 합니다. 같은 규칙을 서버에서 돌릴 수 있게 설계했습니다.
- 온라인: 방장 권위 모델. 전송 계층은 인터페이스 하나이고, 구현은 BroadcastChannel(같은 브라우저 탭끼리)과 **Supabase Realtime**(기기 간) 두 가지입니다. 네트워크로 들어온 모든 메시지는 검증·정리한 뒤 사용합니다.
- 스토리는 순수 데이터 대화 그래프이고(`src/story/`), 규칙·전송·스토리는 모두 Node 테스트로 검증합니다.

## 시작하기

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 생성
npm test         # 단위 테스트 (네트워크 필요 없음)
```

개발용 주소 옵션:

| 주소 | 용도 |
| --- | --- |
| `/?debug` | `window.__courte` 로 게임 상태와 함수를 열어 둠 |
| `/?debug&seed=7` | 그날 밤의 난수 시드를 고정 |
| `/?debug&dtmax=0.2` | 프레임이 느린 환경에서 시뮬레이션 시간을 키움 |
| `/?net=local` | 온라인을 같은 브라우저 탭끼리로 강제 |
| `/?room=ABCDE` | 방 코드로 바로 참가 |

### 온라인 방 설정 (선택)

기기 간 온라인 방은 [Supabase](https://supabase.com) Realtime을 사용합니다. 설정하지 않아도 게임은 동작하고, 같은 브라우저의 탭끼리만 연결됩니다.

1. `.env.example` 을 `.env.local` 로 복사합니다.
2. `VITE_SUPABASE_URL` 과 `VITE_SUPABASE_KEY` 에 프로젝트의 URL과 **publishable(anon) 키**를 넣습니다.
3. 실서버 확인 테스트: `SUPABASE_URL=… SUPABASE_KEY=<publishable> npm test`

> ⚠️ **secret / service_role 키는 코드, `.env*`, 커밋 어디에도 넣지 마세요.** 클라이언트에는 publishable 키만 씁니다. `.env.local` 은 git에서 제외됩니다.

## 프로젝트 구조

```
index.html          마크업 (HUD, 주문서, 결과 카드)
src/
  main.js           씬 구성, 게임 상태, 카메라, UI, 바텐딩 흐름
  room.js           바 공간 전체 (바닥, 벽, 카운터, 백바, 가구, 피아노, 조명)
  figures.js        관절 캐릭터, 걷기/앉기 포즈, 팔 IK, 표정
  glass.js          잔 11종, 액체 수위, 얼음, 가니시, 셰이커
  bottles.js        실제 술병 지오메트리와 라벨
  data.js           재료, 레시피, 가니시 (한국어/영어)
  audio.js          WebAudio 효과음과 음악 합성
  game/             순수 게임 규칙 (월드, 주문, 점수, 방 공유 규칙)
  net/              온라인 방 (전송 추상화, 메시지 검증, 방 클라이언트)
  story/            7일 밤 대본, 대화 엔진, 스틸 컷, 저장
  start.js          시작 화면
test/               Node 테스트 (의존성 없음)
docs/story/         스토리 설계 문서
```

더 자세한 설계 결정과 규칙은 [`CLAUDE.md`](CLAUDE.md) 에 정리되어 있습니다.

## 배포

Vercel에 올려 둡니다. `vite build` 결과인 `dist/` 가 배포됩니다.

```bash
vercel deploy --prod
```

환경 변수 `VITE_SUPABASE_URL`, `VITE_SUPABASE_KEY` (publishable 키만)는 빌드 때 번들에 들어가므로, 값을 바꾸면 다시 배포해야 반영됩니다.

## 알려진 한계

- 3D 모델이 기본 도형 기반이라 인물과 소품이 인형 같습니다. 가장 큰 개선 지점입니다.
- 실제 GPU 프레임 속도와 모바일 실기기 성능, iPhone Safari 소리(무음 스위치 포함)는 충분히 검증하지 못했습니다.
- 온라인은 방장이 나가면 남은 사람 중 한 명이 이어받지만, 서버 권위는 아직 아닙니다(방장 클라이언트 권위).
- 스토리는 혼자 하기 전용입니다.
