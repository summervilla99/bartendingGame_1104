# 라스트콜 라운지

모던 키치 재즈 라운지 바에서 칵테일을 만드는 3D 바텐딩 게임 (프로토타입).

- 손님석에서 NPC 주문을 받고, "칵테일 만들기"를 누르면 바 안쪽으로 카메라가 이동해 바텐딩을 시작해요.
- 재료 붓기 → 셰이크/스터 → 가니시 → 서빙 → 별점과 팁
- three.js (r128) + Vite. 에셋 파일 없이 코드로 만든 지오메트리, 캔버스 텍스처, WebAudio 소리만 써요.

```bash
npm install
npm run dev
```

자세한 구조, 기술 결정, 로드맵은 [CLAUDE.md](./CLAUDE.md) 를 보세요.
